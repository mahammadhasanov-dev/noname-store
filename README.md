# NONAME store

Streetwear store written as a single HTML file.

- Catalogue with live colour and size picker
- Product art drawn as SVG and recoloured per colourway in code
- Cart saved in the browser
- Stripe Elements card checkout (needs a small server to create PaymentIntents; not included)
- Refund, shipping, privacy and terms pages
